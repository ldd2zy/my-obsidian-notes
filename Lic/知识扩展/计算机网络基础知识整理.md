# 一、计算机网络基础知识

先记住一句话：

IP 是门牌号，DNS 是电话簿，网关是小区大门，子网掩码是判断是不是同一个小区，局域网是小区内部，外网是城市和互联网，NAT 是小区前台帮你转接外面。

## 1. IP 地址：设备在网络里的门牌号

IP 地址用来标识一台设备在网络中的位置，例如：

```text
192.168.1.10
8.8.8.8
```

IPv4 地址通常由 4 段数字组成，例如 192.168.1.10。

现在还有 IPv6，地址更长，小白先重点理解 IPv4。

IP 常见分两类场景。

### 公网 IP

能在互联网上被访问的地址，像真实城市地址。

例如你查“我的 IP”看到的那个地址，通常是运营商给你的公网 IP，或者你家路由器出口的公网 IP。

### 私网 IP 或内网 IP

只在小范围内部使用，外网不能直接访问。常见私网段有：

- 10.0.0.0 到 10.255.255.255
- 172.16.0.0 到 172.31.255.255
- 192.168.0.0 到 192.168.255.255

你家里电脑常见 192.168.1.100、192.168.0.101，这就是内网 IP。

### 几个特殊地址

- 127.0.0.1：本机自己，叫回环地址
- 0.0.0.0：常表示所有地址或未指定地址
- 169.254.x.x：设备没拿到 DHCP 地址时可能出现的自动地址，通常说明网络有点问题

## 2. 子网掩码和网段：判断是不是自己人

只有 IP 还不够，还要知道这个 IP 属于哪个网络。这时用子网掩码。

常见例子：

- IP：192.168.1.10
- 子网掩码：255.255.255.0
- 网段：192.168.1.0/24

这里的 /24 表示前 24 位是网络部分。通俗说，192.168.1.x 这些设备在同一个局域网网段里。

同一网段内通信，通常不经过网关，直接通过交换机或 Wi-Fi 找到对方。

不同网段通信，就要把数据交给网关转发。

比喻：

- 同小区邻居：直接串门
- 去别的城市：先出小区大门，也就是走网关

## 3. 网关：网络的出口大门

默认网关通常是你路由器的内网地址，例如：

- IP：192.168.1.10
- 子网掩码：255.255.255.0
- 默认网关：192.168.1.1
- DNS：192.168.1.1 或 8.8.8.8

当电脑发现目标 IP 不在自己网段，就会把数据发给默认网关。

所以网关可以理解成：

我不知道怎么去外网，先把包交给大门保安，也就是路由器。

家里路由器通常同时是：

- 网关
- DHCP 服务器
- NAT 设备
- DNS 代理或转发器
- Wi-Fi 接入点

## 4. 局域网、内网、外网

### 局域网 LAN

小范围网络，比如家里、学校、公司。

你手机、电脑、电视连同一个 Wi-Fi，通常就在同一个局域网。

### 内网

一般指私有网络，使用私网 IP。比如公司内网、家庭内网。

内网设备可以访问外网，但外网通常不能直接访问内网设备。

### 外网或互联网 WAN

更大的网络。运营商、互联网服务商、网站服务器所在的网络。

你家路由器有一个 WAN 口，就是接外网的。

### NAT：内网多设备共享一个公网 IP

家里手机、电脑、电视都是 192.168.x.x，但对外上网时，路由器会把它们转换成同一个公网 IP。

这就像小区里很多住户，对外只有一个小区前台电话。外面打进来要先经过前台转接。

NAT 让内网设备能上网，但也导致外网不能随便直接访问你家内网设备。要做端口映射或内网穿透才行。

## 5. DNS：把域名翻译成 IP 的电话簿

你访问 www.baidu.com，电脑其实不知道百度在哪，它需要知道对应 IP。DNS 就是干这个的。

比喻：

你记得张三这个名字，但快递需要地址。DNS 就是把张三翻译成某小区某门牌号。

DNS 解析大致过程：

1. 浏览器缓存里找
2. 系统缓存或 hosts 文件里找
3. 问本地 DNS 服务器，比如路由器或运营商 DNS
4. 本地 DNS 再向上问根 DNS、顶级域 DNS、权威 DNS
5. 拿到 IP 后，浏览器去连接这个 IP

常见 DNS：

- 8.8.8.8：Google DNS
- 114.114.114.114：国内常见公共 DNS
- 223.5.5.5：阿里 DNS
- 1.1.1.1：Cloudflare DNS

注意，DNS 不是网络本身，它只是帮你查地址。

DNS 坏了，QQ 或微信有时还能用，因为它们的服务器 IP 可能已被缓存或直接配置；但网页域名可能打不开。

## 6. MAC 地址：局域网里的设备身份证

IP 是门牌号，MAC 是网卡硬件地址，通常长这样：

```text
00:1A:2B:3C:4D:5E
```

在同一局域网内，设备最终要通过 MAC 地址把数据交给具体网卡。

可以理解为：

- IP：你现在的住址
- MAC：你的身份证或设备硬件编号

同网段通信时，常会用 ARP 协议问：谁是这个 IP，你的 MAC 是多少。

## 7. DHCP：自动发 IP 的管理员

如果手动配 IP，很麻烦。DHCP 负责自动分配：

- IP 地址
- 子网掩码
- 默认网关
- DNS 服务器

你连 Wi-Fi 后自动拿到 192.168.1.100，通常就是路由器 DHCP 分配的。

比喻：新住户入住，物业自动给你分房号、门禁卡和快递地址。

## 8. 端口：一台设备上的房间号或服务窗口

IP 找到设备，端口找到设备上的具体服务。

常见端口：

- 80：HTTP 网页
- 443：HTTPS 加密网页
- 53：DNS
- 22：SSH 远程登录
- 3389：Windows 远程桌面

比喻：

IP 是小区楼栋门牌，端口是这栋楼里的哪个窗口。

www.xxx.com:443 就是找某台服务器的 443 窗口。

## 9. 协议：大家沟通的语言和规则

常见协议：

- HTTP 和 HTTPS：网页访问，HTTPS 是加密版
- TCP：可靠传输，像挂号信，确认对方收到
- UDP：快但不保证，像广播或快递不签收
- ICMP：ping 用的协议，测试通不通
- ARP：局域网里通过 IP 找 MAC
- DHCP：自动分配 IP
- DNS：域名解析
- NAT：地址转换，不算严格协议，是网络功能

## 10. 一次上网大概怎么走

你打开 www.example.com：

1. 电脑先查 DNS，问 www.example.com 的 IP 是多少
2. DNS 返回 IP，比如 93.184.216.34
3. 电脑判断目标 IP 和自己不在同一网段
4. 电脑把数据包发给默认网关，比如 192.168.1.1
5. 路由器做 NAT，把你的内网 IP 换成公网 IP
6. 数据经过运营商、互联网路由，到达网站服务器
7. 服务器返回网页数据
8. 数据回到你家路由器，再转回你的电脑
9. 浏览器渲染网页

同网段访问则简单些：

1. 判断目标在同一网段
2. ARP 找对方 MAC
3. 通过交换机或 Wi-Fi 直接发过去，不经过默认网关

## 11. 小白常用排查命令

Windows 命令提示符或 PowerShell：

```bash
ipconfig
```

看本机 IP、子网掩码、默认网关、DNS。

```bash
ipconfig /all
```

看更详细信息，包括 MAC、DHCP、DNS。

```bash
ping 192.168.1.1
```

测试能不能通网关。

```bash
ping www.baidu.com
```

测试域名解析和网络通不通。

```bash
nslookup www.baidu.com
```

专门查 DNS 解析结果。

```bash
tracert www.baidu.com
```

看数据经过哪些路由节点。

Linux 或 macOS 类似：

```bash
ifconfig
ip addr
ping
nslookup
traceroute
```

## 12. 计算机网络基础总结

- IP：网络门牌号
- 子网掩码：判断哪些门牌号属于同一个小区
- 网段：同一个网络范围，如 192.168.1.0/24
- 网关：出小区的门，跨网段先交给它
- 局域网：家里或公司内部小网络
- 内网：使用私网 IP 的内部网络
- 外网：互联网
- NAT：内网多个设备共享公网 IP 出去
- DNS：域名转 IP 的电话簿
- MAC：网卡硬件身份证，局域网内找设备用
- DHCP：自动发 IP、网关、DNS 的物业
- 端口：设备上的服务窗口
- 路由：数据该往哪走的导航或分拣系统
- 公网 IP：互联网上可路由的地址
- 私网 IP：内网自己用的地址，如 192.168.x.x

## 13. 最容易混淆的几句话

1. IP 不是设备永久身份证，MAC 更像硬件身份证。
2. DNS 不是网络，它只是把域名翻译成 IP。
3. 同网段通信不一定经过网关，跨网段必须经过网关。
4. 内网 IP 不能直接在公网上被别人访问，通常要靠 NAT、端口映射或内网穿透。
5. 路由器通常集成了网关、DHCP、NAT、DNS 转发、Wi-Fi 等功能，但网关只是它扮演的一个角色。
6. 192.168.1.1 常见是网关，不是公网 IP。

如果你能记住这条主线：

IP 找设备，子网掩码判断同不同网段，同网段直接发，跨网段找网关，DNS 负责把域名翻成 IP，路由器做 NAT 带你出内网。

基础网络就入门了。

# 二、什么是路由

路由就是数据包该往哪走的选路过程。

通俗说，路由是网络里的导航系统，决定一个数据包从当前设备出发，下一步交给谁。

注意区分两个词：

- 路由：一个动作或过程，给数据包选路
- 路由器：干这个事的设备，也可以理解成专业导航员加多个网络接口的转发设备

## 1. 一句话理解路由

IP 负责找哪台设备，路由负责怎么走到那台设备。

比如你的电脑要访问 www.baidu.com：

1. DNS 查出百度服务器 IP，比如 110.242.68.66
2. 你的电脑发现这个 IP 不在我家局域网 192.168.1.0/24 里
3. 于是查自己的路由表，问去外网该走谁
4. 路由表说，不知道具体怎么走，就先交给默认网关 192.168.1.1
5. 路由器再继续查它的路由表，决定下一步交给运营商
6. 一路一跳一跳转发，最后到达百度服务器

所以：

路由就是每一步都问，下一跳交给谁。

## 2. 路由表：设备脑子里的路线表

每台电脑、手机、路由器里都有路由表。它大致包含这些信息：

- 目标网段：我要去哪里
- 子网掩码：这个哪里范围多大
- 下一跳：下一步交给谁
- 出口接口：从哪块网卡或哪个接口出去
- 度量值：多条路都能走时，哪条更优

一个简单例子：

```text
目标网段 192.168.1.0，子网掩码 255.255.255.0，直接可达，出口为本地网卡
目标网段 0.0.0.0，子网掩码 0.0.0.0，下一跳为 192.168.1.1，出口为本地网卡
```

第二条就是默认路由，表示去外网都先给网关。

## 3. 默认路由：最常用的兜底路线

你家里电脑的路由表里通常有一条默认路由，意思是：

所有我不知道具体怎么走的地址，都先交给默认网关。

这就像你出门：

- 去隔壁邻居家：知道具体门牌，直接去
- 去外地：不知道具体路线，先出小区大门，到车站再说

家用场景里，默认网关通常就是默认路由的下一跳。

## 4. 路由器和网关是什么关系

- 网关：一个网络通往另一个网络的出入口，偏角色概念
- 路由器：执行路由和转发功能的设备
- 默认网关：你电脑默认把跨网段数据交给的那个地址，通常是路由器内网口，比如 192.168.1.1

可以这样说：

路由器是设备，网关是它扮演的角色，路由是它做的事。

## 5. 同网段要不要路由

通常不需要经过路由器选路。

比如：

- 你的电脑：192.168.1.10/24
- 对方电脑：192.168.1.20/24

它们在同一网段 192.168.1.0/24，电脑会通过 ARP 找到对方 MAC，然后经交换机或 Wi-Fi 直接发过去。

但如果是：

- 你的电脑：192.168.1.10/24
- 目标：8.8.8.8

不在同一网段，就要走默认网关，也就是进入路由转发流程。

## 6. 路由选择怎么选：最长前缀匹配

如果路由表里有多条路都能匹配，路由器一般选最具体的那条，也就是最长前缀匹配。

比如目标 192.168.1.50，路由表有：

- 192.168.0.0/16，下一跳为 A
- 192.168.1.0/24，下一跳为 B
- 0.0.0.0/0，下一跳为 C

会选 192.168.1.0/24，下一跳为 B，因为它最具体。

/24 比 /16 更精确，/0 是最后兜底。

比喻：

- 默认路由：去外地先到火车站
- /16：去江苏省走这条
- /24：去南京市某小区走这条

越具体越优先。

## 7. 静态路由和动态路由

### 静态路由

管理员手动写死，例如：

```text
去 10.0.0.0/24，下一跳交给 192.168.1.2
```

优点：简单、可控。

缺点：网络变了要手动改。

### 动态路由

路由器之间自动交换路由信息，自动算路。常见协议：

- OSPF：企业或园区网常见
- BGP：互联网骨干、运营商之间用
- RIP：老式小型网络，现在少
- IS-IS：大型运营商网络

家用一般不需要你配动态路由，路由器默认路由指向运营商就行。

## 8. 家用路由器里发生了什么

你家的路由器其实是个多功能一体机：

- 对内：LAN 口、Wi-Fi、DHCP、交换机
- 对外：WAN 口接光猫或运营商
- 做网关：内网设备跨网段先找它
- 做 NAT：把 192.168.x.x 转成公网 IP
- 做路由：查路由表决定数据往哪发
- 做 DNS 转发：帮内网设备查域名
- 做防火墙：挡一些外网访问

所以家用路由器不只是路由，它是路由、NAT、DHCP、DNS 转发、交换、Wi-Fi、防火墙的合集。

## 9. 用快递比喻路由

你寄快递到北京市朝阳区某小区：

- IP 地址：最终收件地址
- DNS：查地址的电话簿
- 路由表：快递分拣中心的路线表
- 下一跳：下一站分拣中心
- 默认路由：不知道怎么走，先发往总转运中心
- 路由器：分拣中心或转运站
- 网关：你所在小区的出口

快递不是一次从你家飞到北京，而是一站一站转发。路由也是这样，数据包一跳一跳走。

## 10. 查看路由表的命令

Windows：

```bash
route print
```

或者：

```bash
netstat -rn
```

Linux：

```bash
ip route
```

macOS：

```bash
netstat -rn
```

你可能会看到类似内容：

```text
default via 192.168.1.1 dev wlan0
192.168.1.0/24 dev wlan0
```

意思是：

- 去 192.168.1.x：本地 Wi-Fi 直接发
- 去其他所有地方：先交给 192.168.1.1

## 11. 路由总结

路由就是给数据包选下一跳。

- 同网段：通常直接发，不经过路由
- 跨网段：查路由表，交给下一跳
- 不知道具体怎么走：走默认路由，通常就是默认网关
- 路由器：执行路由和转发的设备
- 网关：跨网络的出入口角色
- 路由表：设备里的路线表
- 最长前缀匹配：越具体的路线越优先

记住一句最白的话：

IP 是终点地址，路由是导航路线，网关是第一个出口，路由器是路口的分拣站。

# 三、最后总结

## 计算机网络主线

IP 找设备，子网掩码判断同不同网段，同网段直接发，跨网段找网关，DNS 负责把域名翻成 IP，路由器做 NAT 带你出内网。

## 路由主线

IP 是终点地址，路由是导航路线，网关是第一个出口，路由器是路口的分拣站。
